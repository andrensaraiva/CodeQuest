# Unity Support

Unity is planned correctly but not forced into the MVP runtime.

Layer 1, implemented now:

- Pure C# game logic exercises: health, damage, XP, dungeon access, turn result.

Layer 2, future:

- Unity script analyzer for pasted `.cs` scripts.
- Check MonoBehaviour, Start/Update, SerializeField, Time.deltaTime, naming, and separation of logic/presentation.

Layer 3, future:

- Unity project submissions with GitHub URL, scripts, screenshots, video, and written explanation.
- Teacher rubrics and feedback.

The frontend includes a Unity Portal placeholder route.
