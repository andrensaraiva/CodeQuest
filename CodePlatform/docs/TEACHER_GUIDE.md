# Teacher Guide

1. Log in as `teacher@codequest.dev`.
2. Open Dashboard to see classes, students, submissions, and difficult exercises.
3. Open Classes to create a class or view the seeded class.
4. Share invite code `JOGOS2026` with students.
5. Open Builder to create a simple C# exercise.
6. Open Reports to view class progress and students needing support.

The seeded C# track is shared for MVP. A future assignment table should connect specific tracks to specific classes.
