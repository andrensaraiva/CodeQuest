# Design System

Direction: original dark gaming/community UI inspired by the broad visual language of game creator platforms, without copying branding, layout, logos, or exact UI.

## Palette

- Background: `#080b0f`
- Surface: `#101720`
- Elevated surface: `#121a23`
- Primary accent: `#35ff7a`
- Success: green accents
- Secondary: cyan and purple
- Warning: yellow
- Error: pink/red

## Components

- Cards: rounded `12px`, subtle border, dark surface.
- Buttons: primary neon green, secondary dark bordered, ghost minimal.
- Badges: pill labels for language, difficulty, status, XP.
- XP bars: green to cyan/purple gradient.
- Module cards: status, title, progress, lessons/exercises.
- Ranking cards: positive progress wording, never shaming.
- Teacher cards: dense dashboard cards and tables.

## Mobile Behavior

The MVP is responsive. Desktop gets a sidebar; smaller screens keep the content readable but can be improved with a mobile nav drawer later.
