# Student Guide

1. Log in as `student1@codequest.dev`.
2. Open Dashboard to see XP, level, current quest, badges, and ranking.
3. Open Learning Map.
4. Choose a module, read a lesson, and start an exercise.
5. Use Run to check visible tests.
6. Use Submit to run all tests and earn XP on success.
7. Open Badges and Ranking to see progress.

The runner is mocked in the MVP but the UI behaves like a real judge.
